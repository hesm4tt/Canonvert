Installing Canonvert

Version 1.0.4 is available. Download the unsigned IPA or add the SideStore source using the links below.

Direct IPA

Download the unsigned IPA from GitHub Releases, then install it using a compatible sideloading tool and your own signing setup.

SideStore

Add the Canonvert SideStore source in SideStore, then install the app from the source.

LiveContainer

Download the IPA above and import it into LiveContainer following its current installation instructions. Canonvert is distributed unsigned; a compatible device and signing workflow are required.

Need a hand? Open an issue in the GitHub repository.

Formats & exports

Canonvert accepts supported HEIF/HEIC images and DNG/Apple ProRAW files from Photos or Files. RAW development depends on iOS and the source file being supported by Apple's imaging frameworks.

Choose the Everyday, Flash, or Night look, then fine-tune it with live sliders or save custom looks on-device. Capture new images in the built-in camera with the entire 3:4 viewfinder visible, a 3 × 3 grid, and maximum supported still-image quality. After capture, the photo stays pinned above the scrolling customizer. A separate export step lets you choose HEIC or JPEG and Camera Roll or a Files location. On supported iPhones, the camera can capture Apple ProRAW (DNG); ProRes RAW is a video format, not a still photo format. Export filtered images to Camera Roll or Files as HEIC (a HEIF format) or JPEG. Canonvert renders at the source image's dimensions and uses the highest encoder quality available in iOS. The selected look is baked into the exported pixels.

The ELPH 360 HS A captures JPEG rather than RAW. Canonvert develops supported RAW files on-device and applies an inspired rendering; it does not recreate Canon's proprietary processing pipeline.

Metadata

Canonvert carries supported source metadata into exports, which can include capture date and time, GPS location, orientation, and original camera make/model. Availability depends on the input format and what iOS exposes. Exported image dimensions are not intentionally reduced.

The app identifies its processing software in the output metadata where supported. It does not replace the source camera identity with Canon.

Privacy

Photo selection, processing, and export happen on your device. Canonvert does not upload your photos to a Canonvert server. You choose which image to open and where to save the result.

When using the Files picker, iOS grants access to the selected item. The app requests camera access only when you choose Camera and photo-library access only for the actions you choose. No account is required.

Canonvert is an independent project and is not affiliated with, endorsed by, or sponsored by Canon Inc.

Compatibility

Canonvert is an iOS app distributed as an unsigned IPA. A compatible iPhone running iOS 16 or later and a personal sideloading/signing setup are needed. Device compatibility also depends on the sideloading tool and signing setup you use.

SideStore and LiveContainer have their own device and setup requirements. Refer to their official documentation for current instructions.
